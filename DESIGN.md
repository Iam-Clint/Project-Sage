# SAGE interface decisions

The supplied references establish charcoal surfaces, violet accents, rounded panels, a narrow sidebar, and a study dashboard with activity charts. Preserve that direction across welcome, authentication, learning, and progress screens.

- Use Inter with tight display tracking and comfortable body leading. Use tabular numbers for scores and time.
- A single violet accent identifies primary actions and current navigation. Green confirms success; amber identifies topics to revisit.
- Every control responds immediately. Pointer press feedback uses a 100–160 ms transform transition. Frequent navigation, keyboard actions, and functional charts change instantly.
- Occasional dialogs use short opacity/transform transitions. Base UI owns focus management and dismissal. Sonner owns notifications.
- Reduced motion, transparency, contrast, touch targets, and visible focus are built in. No ambient loops, animated counters on load, or hover movement on data cards.
- Keep curriculum content distinct from AI-generated output. This frontend uses authored examples and deterministic feedback; live AI and retrieval will be integrated later.
- Demo data is labelled. A real signed-in learner starts with an empty progress record. Store frontend progress locally per learner until a server-side learner model is available.
